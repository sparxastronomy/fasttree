# fasttree
SYCL based backend for fast tree construction and neighbour query for cosmo sims


## Dashboard
Benchmark results are hosted and served here on the following dashboard: [sparxastronomy.github.io/fasttree-dashboard/](https://sparxastronomy.github.io/fasttree-dashboard/)   
It might take a couple of seconds to load the dashboard as it renders the dashboard in the browser without any SSR
